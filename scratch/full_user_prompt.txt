# 11. EMPTY-CANVAS DETECTION — RECOMMENDED APPROACH

For transition boundary frames, combine signals such as:

```text
color variance / standard deviation
edge density
entropy
foreground occupancy proxy
difference from known template background
```

A frame may be suspicious if:

```text
very low variance
AND very low edge density
AND close to template cream background
```

Use conservative thresholds.

Output:

```text
emptyCanvasSuspects
```

rather than pretending semantic certainty.

QA states:

```text
0 suspects -> PASS_AUTOMATED
>0 suspects -> REVIEW_REQUIRED
```

If robust automated detection is not reliable:

```text
EMPTY_CANVAS = PENDING_HUMAN
```

is acceptable.

Do not fake PASS.
